## 🏗️ معماری تکنیکی

### Stack

```
Frontend:
├─ Android (Kotlin)
├─ Jetpack Compose (UI)
├─ Material Design 3
└─ Glass Morphism Animations

Backend:
├─ Firebase Firestore
├─ GitHub CDN (images)
├─ GitHub Actions (CI/CD)
└─ Firebase Hosting (future web)

Data:
├─ Firestore: Game data
├─ GitHub: Images (CDN)
├─ Local: Cache + Offline
└─ Admin: HTML + Firebase REST
```

### Performance Stack

```
کارایی:
├─ RecyclerView virtualization (8-10 items in memory)
├─ Coil image caching (aggressive)
├─ Font pooling (load once)
├─ Stateless design (no local state needed)
└─ GPU-accelerated animations

نتیجه:
└─ 80-100 MB RAM ✅
└─ 59 FPS scrolling ✅
└─ <400ms startup ✅
```

### Prerequisites
```bash
# ۱. Git
git --version
```

```bash
# Clone
git clone https://github.com/alitanhaii1970-commits/game-settings-app.git
```
